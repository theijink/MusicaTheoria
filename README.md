# MusicaTheoria
Python tool for learning music theory during practice. Initially set up for Guitar/Bass. 

## Pre-requisites
- `brew install python3`
- `brew install python-tk`
- `source venv/bin/activate`
- `python -m pip install -r requirements.txt`

## Usage
>*Currently not every feature is implemented, and the CTk version of the application is not functional*

- Run the tk version: `python app.py`
- Run the ctk version: `python application.py`
